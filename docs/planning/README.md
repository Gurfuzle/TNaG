# Planning

This directory holds **plan documents** — one Markdown file per proposed change
or new idea. We write the plan here, agree on it, break it into small tasks, and
only then implement. See [`../process.md`](../process.md) for the full workflow.

## How to use

1. Copy [`TEMPLATE.md`](./TEMPLATE.md) to a new file named after your idea, e.g.
   `add-event-rsvp.md`.
2. Fill it in and iterate on it.
3. When the plan's tasks are all done, either leave the file as a record or move
   it into a `done/` subfolder.
